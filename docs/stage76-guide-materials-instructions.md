## 1. 第1部: 資料の候補を広げる

1. **原因を調べる**: 「遠くても構いません。今見られる花と場所を教えて」で、`ask answer` と `ask brief` の候補が神奈川・東京だけになる理由を調べる（段階74で、地域ごとの節を入れたはず）。範囲の判定（wide）が効いているか、候補が「今年の現況がある場所」に絞られていないか、花の種類が今の季節で絞られすぎていないか。分かったことを報告書に書く。
2. **資料の候補に、2つの種類を持たせる**:
   - **今年の現況がある候補**（今までどおり）。
   - **例年の目安の候補**: 今年の現況はないが、例年の時期が今（または指定の日付）に当たる名所。AI は「例年は」と書いて案内できる。
3. 範囲が広いとき（wide）は、**地域の組ごとに**（東京・神奈川／埼玉・千葉・茨城／栃木・群馬／山梨・長野／静岡／新潟・南東北）、例年の目安の候補を最大2件ずつ資料に入れる。範囲の指定がないときも、近場だけにならないよう、遠くの地域の例年の候補を合わせて3件まで入れる。
4. 確かめること: 3番の資料に、3つ以上の地域の組の候補が入ること（例: 記録にあれば、群馬の桜山公園の冬桜）。テストを足す。

## 2. 第2部: 知識カードをテーマからも引く

1. `ask brief` が、質問の場所・種・山のカードに加えて、**テーマ**（紅葉・冬鳥・冬の花・観察の作法 など）と**季節**からもカードを引くようにする。1つの資料で合わせて**最大8枚**。場所・種に直接結びつくカードを優先する。
2. 資料の中で、カードごとに**結びつき**を示す: 「この場所の話」「この種の話」「一般の話（テーマ）」。
3. docs\guide-voice.md に決まりを足す: **「一般の話」のカードは、一般の説明としてだけ使う。特定の場所や行事に結びつけて書かない**（段階75の9番で、観察会の説明に、関係の薄い地質のカードをつないだ例があった）。迷ったら使わない。
4. 確かめること: 段階75でカードが0枚だった4問で、カードが1枚以上入ること。

## 4. 第4部: 冬季閉鎖の記録

1. 範囲内で、**毎年の冬に閉まる道路・施設**を、道路管理者（国・県）や施設の公式ページで確かめて記録する（種類は「安全・規制」。毎年くり返すものとして、例年の閉鎖の時期を持つ。今シーズンの日付が公式に出ていれば、年つきで持つ）。最大20件。
2. 優先: 山のカードがある山域と、名所カタログの名所に行くための道路（例: 国道299号 麦草峠、ビーナスライン、志賀草津道路、金精道路、霧降高原道路、富士山の登山道と周辺の道路、乗鞍・上高地方面）。確かめられなかったものは報告書に列挙する。
3. `ask brief` は、候補の場所・山に結びつく冬季閉鎖を、資料の「確かめた事実」に入れる。閉鎖の時期に当たる候補は、順位を下げるのではなく、**資料にそのことを明記する**（AI が「この時期は道路が閉まります」と書けるようにする）。
4. 確かめること: 八ヶ岳の資料に、白駒池方面の道路の冬季閉鎖が入ること（公式で確かめられた場合）。

## 5. 第5部: 細かい直し

1. **出典**: 最終の文の出典には、文の中で根拠にしたものだけを並べる（段階75の1番で、使っていない出典が並んだ）。URL のない出典を出さない。霧ヶ峰自然保護センターの発行元の区分を確かめて直す（段階75の8番で「公式ではありません」・URL なしになった）。
2. **確かさの表し方**: 公式でない出典は、文中では「紹介サイトによると」のように短く書く。「（紹介サイトの記載で、公式ではありません）」のような長い断りを文中に入れない。公式かどうかは、最後の出典で分かればよい。guide-voice.md と `ask verify` の出力を合わせる。
3. **同じ言い回しの繰り返し**: guide-voice.md の例文を、そのまま写さないよう明記する。同じ説明（紅葉が山の上から下りる、鳥に近づかない など）を毎回入れない。その質問で意味があるときだけ書く。
4. **質問と見なす検査**: 新しい形では、「どちらも…ご確認ください」のような案内の文を、最後の質問と見なさない。読む人への問いかけ（「〜しますか?」「どちらにしますか」など）だけを止める。今までの形の検査は変えない。
5. **書き手の道具**: 新しい形の書き手（サブエージェント）は、資料と手本を読むことと、下書きを書くことだけを行う。コマンドの実行や Web 検索をさせない。
6. **SKILL.md の整理**: 上限15,000バイトに対して、余裕を2,000バイト以上作る（内容は消さず、docs に移して参照にする）。そのうえで docs\guide-mode.md への参照を足す。
