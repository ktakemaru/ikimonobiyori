## 1. 最重要の発見: 東京都公園協会の紅葉情報は、今は昨シーズンの最終版のまま

- URL: https://www.tokyo-park.or.jp/special/kouyou/index.html（発信者: 公益財団法人 東京都公園協会、区分: 公式）
- 2026-11-05 時点の本文は**2025年シーズンの最終版**: 「最終情報更新日：令和7年12月18日（木）17時」。全地点が「落葉」または「散始め」。ページの注記に「令和7年12月22日（月）に閉鎖」とある。meta の説明文は「2026年版」だが本文は更新されていない。
- したがって **2026年の現況としては使わない**。取り込むのは次の2点だけ。
  1. 地点の一覧と樹種・本数（変わりにくい属性。下の表）
  2. 更新の仕組み（読み取りコードの仕様）
- 更新の仕組み（根拠: 東京都 報道発表 https://www.metro.tokyo.lg.jp/information/press/2025/11/2025110407 ）:
  - 2025年は令和7年11月10日（月）〜12月22日（月）に提供。毎週月曜・木曜の夕方に更新（祝日は翌日）。最終更新は12月18日。37公園・庭園が対象。
  - 2026年の開始日は**未確認**。例年11月第2週の月曜ごろの可能性があるが、推測として扱い、断定しない。
- 読み取りコードの仕様（reader: code にする場合）:
  - 「最終情報更新日：令和N年M月D日」を読み、**今シーズン（その年の9月以降）の日付でなければ「前シーズンの情報」として現況に使わない**。
  - 各地点の「紅葉状況」は**文字でなく画像**で、画像の alt テキストに状態名が入る（確認できた値: 「落葉」「散始め」。凡例画像 kouyou-hanrei.gif は読めず、他の状態名は未確認）。凡例にない状態名が来たらその語をそのまま出し、推測で段階に変換しない。
  - 地点ごとに「ひとくちメモ」へのリンクがある（https://www.tokyo-park.or.jp/special/kouyou/memo/index.html の #番号）。

## 3. 高山植物・花の名所

### 仙丈ヶ岳（花暦は足せない。山の名所の記載のみ）
- 山梨県観光（公式の観光情報）https://www.yamanashi-kankou.jp/kankou/spot/p1_4647.html : 氷河地形のカールが見られ、多くの高山植物が咲く。広河原に通じる県営林道（南アルプス線・南アルプス公園線）はマイカー規制区間があり、規制は6月下旬〜11月上旬、それ以外は冬季閉鎖。
- 林野庁 中部森林管理局（公式）https://www.rinya.maff.go.jp/chubu/policy/business/conservation/hogorin/2-15.html : 山頂付近に3つのカール、高山植物が非常に豊富。ニホンジカの食害を防ぐため馬の背ヒュッテ付近に防護柵。
