## 満たせなかった点と、次の段階の課題
1. **湖尻の食い違い**(問 3): ユーザーの確認とコードの読み取りが食い違う。人がページ(と HTML の中身)を目で見て、どちらが正しいかを決める必要がある。決まったら、間違っていた側に誤りの印を付ける(`mark-erroneous`)。コードの読み方が間違っていたなら、合成の見本でテストを足して直す。
2. **東北の範囲**(問 7): 期待の文言(福島県南部の一部)と、計算の結果(福島県の大部分)が違う。どちらを期待とするかはユーザーが決める。代表点は推定の座標なので、県境の正確な判定が要るなら国土数値情報などの公式の境界を使う案がある。
3. **現況の薄い地域**: 富士山周辺・都内・軽井沢は、公式の現況ページがまだない(今年の公開前のものを含む)。東京都公園協会の「紅葉を見に行こう!」が出たら足す。
4. **八方尾根の書き方**: 決まった語がなく段階が付けられない。運営者の別のページ(ライブカメラの説明など)に状態の語があるか探す。
