**桜の種類の説明**(ガイド型の答えの材料):
- **冬桜(フユザクラ)**: 山桜と豆桜の交配種といわれる。花は小さく、白〜淡紅色。秋〜冬(10月下旬〜12月)に咲き、春にも咲く二度咲き。
- **寒桜(カンザクラ)**: 淡紅色の一重の花を、1〜2月に咲かせる。**冬桜とは別の種**。出典: https://tabi-mag.jp/gu0100/ / https://www.walkerplus.com/article/1068351/
- **河津桜**: 寒緋桜系と早咲きの大島桜系の自然交配種と考えられ、1月下旬からつぼみがほころび、3月上旬まで咲く。出典: https://www.walkerplus.com/article/1329757/

## A-4. ホタル(関東)

**種類**(出典: https://allabout.co.jp/gm/gc/463681/ / https://tenki.jp/suppl/usagida/2016/06/13/13151.html / https://www.pref.miyagi.jp/documents/53315/arikabetikugennzibotaru.pdf / https://weathernews.jp/news/202505/270196/ / https://www.pref.iwate.jp/_res/projects/default_project/_page_/001/014/229/himehoraruannai.pdf):
- ゲンジボタル: 関東では5月下旬〜6月中旬(全国で5月下旬〜6月下旬)。大きく光が強い。水のきれいな川。東日本のゲンジは、光る間隔が約4秒。
- ヘイケボタル: 関東では6月中旬〜8月ごろ。小さく光が弱い。水田・池・湿地など。
- ヒメボタル: 水辺ではなく、湿った森。5月下旬〜7月下旬ごろ(岩手県の資料では7月上旬〜中旬)。光は小さいが黄色く激しく点滅。
- 見る時間: 午後7時ごろから光り始め、20〜21時ごろがピーク。蒸し暑く風のない曇りの夜に多い。光(懐中電灯・フラッシュ)は禁物。出典: https://www.niigata-kankou.or.jp/tanoshimu/summer/hotaru/index.html
