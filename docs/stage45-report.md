- **ウォーカープラスの一覧・個別ページには、地点ごとの「今の色づき段階」と更新日が出ない。** 出るのは「例年の色づき始め」「例年の紅葉見頃」だけ。トップの「全国約1200か所の色づき段階を毎日更新」は、少なくとも読めたページ(一覧 4+3 ページ、個別 1 ページ)には現れていない。そのため、ウォーカープラスは現況の情報源(status_page)ではなく、**例年の時期の参考(reference_link)**として追加した。今の状態は、これまでどおり tenki.jp・日光市観光協会・箱根町観光協会・神奈川県で読む。
