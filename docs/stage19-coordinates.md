**注意(続き。2026-10-24): この文書の前半(「結論」から「標高の確認」まで)は、推定の座標を作ったときの記録で、推定の座標は使わないことになった(`docs/stage19-decisions.md` D-16)。現在の座標の出所は、末尾の「公式ページの地図の埋め込みの座標」の節。**

26 地点について、公式の発信元の**スポットのページ**(現況の一覧ページからリンクされているページ)を要約の道具(WebFetch)で読み、座標を探した。
公式ページの文章は写していない。ここにあるのは、見つけた数字(または「座標なし」)と、そこから決めた代表点だけ。

## 結論

- **公式ページの座標(緯度・経度の数字)が見つかった地点は 0。** 日光市観光協会・大子町観光協会・箱根町観光協会・やまなし観光推進機構のどのページにも、要約の道具が見える範囲に座標の数字はなかった(大子町のページには「Google Map で開く」のリンクがあるが、座標ではなく検索語だけ)。ページの HTML そのものは読んでいない(要約の道具で読む決まり。スクレイピングのコードを足さない)。そのため、地図の埋め込みの中にだけ座標がある可能性は否定できない(D-10)。
- したがって代表点は**すべて所在地・目印からの推定**(Claude Code の地理の知識による。確認はフェーズ2)。
- 推定の点は、確かな度合いに応じて `location_precision` を下げる。
  - 目印が駅・社寺などで 1 km ほどの誤差に収まると思うもの: `area_1km`(小数 2 桁)。
  - それ以外: `area_10km`(小数 1 桁)。
- 接岨峡・長島ダム・奥大井湖上駅、智満寺の 2 地点は、情報源(`okuooi-koyo`)が承認待ち(`pending`)なので、スポットのページを**読んでいない**(承認前の情報源は読まない)。
