### 2. 名前の形が違う同じ場所を、資料の候補で 1 つに

- `guide_brief.merge_same_candidates`・`same_place`(資料の候補がそろったあと、カードを選ぶ前に行う)。
  - 同じ場所: 同じ市区町村・同じ種(候補の名前とテーマから分かる種が同じ。種が分からなければまとめない)で、両方に座標があれば 200m 以内(`guide_mode.yaml` の `merge_same.max_m`。本人の判断の値)。座標がない(片方でも)ときは、名前の主な部分が同じとき。
  - 名前の主な部分: 括弧の中・空白・「・」・「の」を除き、頭の都道府県と市区町村の名前(「長瀞」のように末尾の町を除いた形も)を除き、種の別名を種の名前にそろえたもの(「長瀞宝登山臘梅園」→「宝登山ロウバイ園」)。それ以外の違い(「宝登山山頂ロウバイ園」など)はまとめない。
  - 表に出す名前: 公式の出典の事実を持つ候補の名前(なければ先の候補)。元の名前は候補の `merged_from`。事実は両方の候補のものを残し、場所の欄を表に出す名前にそろえる(本文はそのまま)。理由・テーマなどは両方を合わせる。カードは元の名前でも結びつく。
