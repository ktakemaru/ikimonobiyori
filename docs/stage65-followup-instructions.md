## 3. 第4部: 「見どころ」の型（11/9 の会話の練習）

背景: 「日光や那須で見どころを教えて」が「今週末の紅葉・花・野鳥のおすすめ」として答えられ、杉並木公園1か所だけになった。「筑波山の見どころを教えて」は、エージェントがその場で調べた4行だけだった。利用者が求めたのは、ネイチャーガイドとしての、その場所の自然の案内。

1. **意図の分類を足す**: 「<場所>の見どころ」「<場所>ってどんなところ」「<場所>で何が見られる」を、新しい型「見どころ」とする（日付のない、場所の質問）。「今週末」など日付があれば、これまでの計画の型。
2. **答えの材料（すべてコードが集める）**: その場所・エリア（段階58のエリア辞書、名所カタログ、sites.yaml の地点）に関係する、
   - 知識カード（ガイドの目。場所の一致。分類の偏りなく最大5枚）
   - 名所カタログの名所（種・例年の時期。季節ごとに並べる）
   - 承認済みの施設（ビジターセンターなど）の名前と、14日以内の発信があればその1行
   - 今年の行事（年つき）
   - 今の季節に関係する現況があれば1〜2行（主役にしない）
3. **答えの形**: 冒頭1〜2文でその場所の自然の特徴（カードの事実から）→ 季節ごとの見どころ（春・夏・秋・冬。記録のある季節だけ）→ 施設 → 今の時期の一言 → 出典。
4. 材料が少ないときは、確かめられたことだけを書く（足りない分を一般知識で補わない）。「観光名所は今回の資料にありません」のような、資料の事情を書かない。
5. 受け入れ: 「日光や那須で見どころを教えて」に、日光・那須の知識カード、日光自然博物館・日光湯元ビジターセンター・那須平成の森（承認済み）、日光市観光協会の名所が出る。「筑波山の見どころを教えて」に、記録のある事実が出る。
6. テストを足す（合成データ）。
