## 2. 第2部: 山のカード（1座ずつ。時間の許す限り）

### 2-1. 1座で作るもの

既存の**知識カードの形**（段階59: 題・分類・場所・事実は最大5項目で1項目60字以内・条件・出典・確度・権利メモ・答えでの出し方）で、1座あたり**4〜8枚**。カードの場所には、sites.yaml の地点 id（mNNN）と山名を入れる（「見どころ」の型と、将来のヤマビヨリとの連携で引けるように）。

| カードの分類 | 中身の例 |
|---|---|
| 植生（季節の仕組み） | 標高ごとの森の移り変わり（山麓の落葉広葉樹林 → 亜高山帯の針葉樹林 → ハイマツ帯・お花畑） |
| 季節の花（場所ごとの見頃の流れ） | 月ごとの代表的な花（花の百名山の選定の花を含む）。月は出典にあるものだけ |
| 鳥・動物（出会い方） | 見られる鳥・動物（ライチョウ、ホシガラス、カモシカなど）と、出会える環境・季節 |
| 地形・地質 | 火山、カール、蛇紋岩・石灰岩など、植物と結びつく地質 |
| 紅葉の時期 | 山頂付近・中腹・山麓の目安（出典にあるものだけ） |
| 保全・安全 | シカの食害と防護柵、高山植物の保護、クマ、ライチョウの保護、立入の制限 |
| 施設 | 近くのビジターセンター・自然観察路（施設台帳にあれば id で結ぶ） |

### 2-2. 調べる先（優先順）

1. 環境省（国立公園・国定公園のページ、自然公園の解説、生物多様性センター）
2. 林野庁の森林管理局（保護林・緑の回廊の解説）
3. 都道府県・市町村の自然・観光の公式ページ、ジオパーク
4. ビジターセンター・自然保護センターの解説・発行物（施設台帳にあるもの。規約の厳しい施設は事実だけ）
5. 紹介サイト（YAMA HACK など。「公式ではありません」の区分）。**山と溪谷オンラインは使わない**（段階55の決定）。tenki.jp・ウェザーニュースも使わない。

### 2-3. 決まり

- **本文を読んで確かめた事実だけ**をカードにする（検索の要約は使わない。段階64 第5部）。PDF は pdfminer.six で読む。読めなければ「PDF 未読」と発行物台帳に記録する。
- 事実は自分の言葉で、短く。原文の文章・図・写真を写さない。
- 年に依存する事実（「2023年の観察」など）は年を明記する。
- 「記録がある」と「いつも見られる」は分けて書く（例: 「ライチョウの生息地」と「出会えるとは限らない」）。
- 災害・閉鎖・規制・通行止めなどの**強い事実**は、公式ページで確かめたものだけ。
- 範囲（横浜から250km前後）の外の山は対象外。
- 1座の調べが25回で足りなければ、作れた分で区切り、報告書に「不足」と書いて次の山へ。

### 2-4. 1座ごとの手順

1. 調べる → カードを `ask knowledge add` で記録（データ置き場。公開リポジトリには入れない）。
2. その山で「見どころ」の質問（「<山名>の見どころを教えて」）を `ask answer` で試し、カードが出ることを確かめる（段階65 第4部ができていれば）。
3. docs\stage66-progress.md に、山名・作ったカードの枚数・分類・使った出典の数・通信回数を1行追記。
4. 5座ごとに、`ask knowledge backup`（commit まで）と、リポジトリ側の変更（あれば）の commit。

## 3. 第3部: 仕組み（必要なら。第2部の前でも後でもよい）
