4. 「台帳にはどのくらいの登録があるの?」（利用者の語での情報源の一覧）
5. 「箱根の紅葉はどう?」（箱根ビジターセンターの発信が、状態の語と種名を別の文で出す）

確認する点: 内部用語・作業の事情が出ない／最後に質問が出ない／文章が読みやすい／事実が一致している／出典が本文と対応している。

## 12. 報告書に必ず書くこと

- 先頭に push の状況、知識カードのバックアップの状況、承認欄の状態
- 各部の結果（済み／未完了／スキップした理由）、判断したこと、次回のやり残し
- 第4部の診断の表（長瀞・河口湖などが、なぜ出なかったか）、名所カタログに追加した地点の一覧
- 承認待ちで隠れている候補の件数と一覧
- 本人の判断が要る事項
