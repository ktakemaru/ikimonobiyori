## 第1部: 種の名前の読み替え

- 新しいモジュール `ikimonobiyori/species_alias.py` と設定 `data/ask/species_alias.yaml`。質問の文の種の名前を、認識した種の名前(カタカナ)に書き換えてから資料・答えを作る(`ask brief`・`ask answer` の入口。資料には `asked`(元の文)と `species_renamed` を残し、資料の Markdown に「種の名前: さざんか → サザンカ」と出す)。
- 種の名前(カタカナ)の出どころ: 名所カタログ・ガイドのカタログの種の語、写真の対応表(リポジトリの表)、野草の花期の表、写真つきページの書き方の表の値、season_place.yaml の species の語。
- **足した書き方の数: 121**(カタカナの名前のひらがな表記を機械的に 3 字以上で作ったもの 96 + 漢字 25(表に書いた 43 のうち、種の名前が一覧にあるもの。残りの 18(金木犀・桔梗・竜胆 など)は種の名前が今の一覧にないので使われない))。漢字は確かなものだけ(山茶花・椿・銀杏・楓・石蕗・水芭蕉・満天星・欅・唐松・落葉松・橅・梟・鶯・鴛鴦・隼・鶚・鵟・小白鳥・大白鳥・大鷹・百合鴎・駒草・稚児車・箒草・箒木 など)。「薄」(薄い)・「皐月」(月の名前)・「牡丹」(ボタン)・「鷹」「鷺」「鶴」(仲間の総称)は足していない。
- season_place.yaml の species の表にすでにある書き方(あじさい・紫陽花・梅・ふじ など)は、その表で引けるので**書き換えない**(今までの答えを変えない)。ただしページの題では、表のひらがなの書き方をカタカナで出す(「あじさいの見頃と見どころ」→ 題のテーマは「アジサイ」)。
- 取り違えの防止とテスト(`tests/test_stage82_names.py`): 2 字のひらがなは前後の字がひらがな(助詞以外)・漢字(送り仮名)のとき種にしない、除く形(ふじさん・をきく など)。テストにした例: 「ふじさんの紅葉」→ 藤にしない、「秋はすすきの名所」→ 蓮にしない、「話をきくと楽しい」→ 菊にしない、「もみじの見頃」「かもを見たい」「しめ縄」「不思議な花」は書き換えない、「椿寒桜」の椿は書き換えない、「コケモモ」「コケリンドウ」を苔にしない、「大きく」の「きく」を菊にしない。
- 確かめ(テスト): 「さざんかの見頃と見どころを教えて」の資料にサザンカのカードと名所(亀戸中央公園・国営昭和記念公園など)が入り、題は「サザンカの見どころ」。「ツバキの見頃と見られるところを教えて。ツバキとさざんかの違いも教えて」の題は「ツバキとサザンカの違い」(題のテーマの語の重なりも 1 回に)。カタログの種が 2 つある質問(「ツバキとサザンカ」)は 2 つとも認識する。
