## 判断したこと

- ブランチは main から(stage81 はマージ済みだった)。
- 種の名前の読み替えは、今の種の表(season_place.yaml の species)にすでにある書き方は書き換えない(今までの答え・題を変えないため)。新しい書き方は、カタカナの名前のひらがな(3 字以上)と、確かな漢字だけ。2 字のひらがな(かも・しめ・しぎ)は作らない。
- 照合の「違い」の語は「との違い・と違う・違いは」だけにした(時期・見どころの説明の「違い」を止めないため)。仲間の総称(猛禽類・カモなど)とバラ・秋バラは種として照らさない。
- 苔の記録の subject は flowers にした(調べた記録の種類が flowers・birds だけのため)。季節の花の候補に出ないよう、苔などのテーマの記録は既定では読み込まない(read_records の include_themes)。
- 白駒の池の市町村は佐久穂町にした(指示書は佐久穂町・小海町。記録は 1 つの市町村なので)。
- 苔の名所の追加(4 か所まで)と、コキアのほかの名所は行わなかった(写真の点検を先にした。コキアは公式で例年の時期を確かめられなかった)。
- 箱根美術館の開館日・休館日は、施設のページの運営者の欄で発行元を確かめられず読まなかったので、記録していない。
- 写真の一覧画像は、途中から Windows の描画(PowerShell)が自動の許可判定で止められたので、1 枚ずつ開いて見た(点検の中身は同じ)。
- 写真の判定で、撮影者名・日付・URL の焼き込みがある写真(同じ撮影者の古い写真が多い)は「大きな透かし文字・日付の焼き込みが目立つ」として不可にした。小さな署名(写真の隅の小さい文字)は可にした。
- 別の種の疑いは「疑い」として外しただけで、正しい名前は記録していない(指示どおり)。チュウサギの取り直しの写真はファイル名・説明にチュウサギとあり、見た目からは決め直さず可にした。
- サルビアは園芸品種(水戸市植物公園の 'Peach')の写真を可にした(種の写真として可。色は一般的な赤ではない)。イチョウは墓地の木の黄葉の写真を可にした(墓石が写るが、人・血などの決まりには当たらない)。
