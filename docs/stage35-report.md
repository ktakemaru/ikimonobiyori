# 段階35 報告(試用で見つかった穴の修正・第1部。指示書 `biyori-hub/docs/stageH9-instructions.md` の「段階R2」)

番号: 既存の報告書・ブランチは stage34 まで。次の空き番号の **35** を使った(指示書の「段階R2」)。ブランチ `stage35`(main の最新 `1b3d722` から)。

## できたこと
1. **穴3: 新しい・古いは状態の日付で判定**(`ikimonobiyori/observations.py`)
   - 判定の基準日は状態の日付(`state_date`)。欄が空でも、原文の「10/25現在」「10月8日現在」は状態の日付として読む(`state_date_from_text`。読むたびに計算し、記録のファイルは書き換えない)。状態の日付がない記録だけ、読んだ日で判定する。幅(紅葉・花 2 日、野鳥 7 日)は変えていない。
   - 出力の `freshness` に基準(`basis`: state_date / read_at)と基準日(`basis_date`)を足した。
   - 例: くりはま花の国「10/27時点」の記録を 11/1 に読んでも、11/1 の質問では「古い」(`plan` の `items` に出る)。なお、11/1 朝の試用でも `plan` はくりはま花の国を「古い」と出していた(窓口が読みに行かなかった。ハブ側で、読みに行かずに答えたら検査器が落とすようにした)。
2. **穴3: 例年の時期と今年の行事を分ける**
   - 名所カタログの `flower_windows` で、注記が行事の期間を表すもの(`data/observations/policy.yaml` の `typical.event_note_words`: 期間・フェスタ・フェスティバル・まつり など)や行事と同じ月日のものは、例年の時期に使わない(`event_periods_not_typical` に残す)。花菜ガーデン(ローズフェスティバル)・小田原フラワーガーデン(ローズフェスタ)・三溪園(2025 年の菊花展)が当たる。
   - 記録から読んだ今年の行事(`event`)と同じ月日の「例年の時期」も行事の期間とみなす(受け入れテストで、川崎大師の菊花展の期間 10/29〜11/19 が例年の見頃に出ていたのを見つけて直した)。
   - 記録の `typical` で「開催」「予定」「期間」を含むもの(例: 「例年10月下旬から11月下旬にかけて開催」「11月中旬頃に見頃を迎える予定」)も例年の時期に使わない。
   - 名所の一覧のくりはま花の国の「11月上旬～11月下旬」(2025 年のコスモス園の開放期間に近い値)に `event_derived: true` を付けた。
   - 決まった文 `typical_line`: 「例年の見頃: …」/「例年の時期は分かりません(今年の行事「○○」は○/○〜○/○)」。
   - 例年の時期が分からなくても、対象の日に行事がある花の名所は前の段(tier 2)に置く。
3. **穴2: 野鳥は「この時期に見られる鳥」**
   - 野鳥の候補には「例年の見頃」の関係(`relation_label`)を出さない。代わりに `season_line`(決定論の一文)と材料 `season_birds`・`inat`。
   - 材料: ①iNaturalist の過去の記録の相対頻度(既存の野鳥の仕組みと同じ式・同じ問い合わせ。キャッシュにあるものだけを読む。古くても使い、取得の日を添える)、②前の年の同じ時期(前後 30 日。仮置き)の観察の記録、③名所の一覧に書き写した紹介(`season_birds`)。
   - **神奈川の区域を 5 つ足した**(新規 `data/observations/bird_areas.yaml`。`data/sites.yaml` の bird_areas とは別にして、既定の問い合わせ・定期実行・合成の表示・既存のテストの区域の一覧には入れない。`main --area <ID>` で明示したときだけ取れる。座標は area_10km の丸め): 境川遊水地・舞岡周辺 / 横浜自然観察の森周辺 / 鶴見川遊水地周辺 / 生田緑地周辺 / 座間谷戸山・相模原公園周辺。名所の一覧の神奈川の探鳥地 7 件に `bird_area` を付けた。
   - 実通信(2026-11-01、ユーザーの指示書による。計測フック `BIYORI_REQ_LOG`・許可ホスト `api.inaturalist.org`・`--max-requests 2`/区域): 対象日 11/2 の窓(前後 1 週・過去 5 年)で **10 リクエスト(すべて HTTP 200)**。鳥類の記録の総数: 境川遊水地・舞岡周辺 50、横浜自然観察の森周辺 53、鶴見川遊水地周辺 127、生田緑地周辺 398、座間谷戸山・相模原公園周辺 106(いずれも min_total_observations=30 以上)。横浜自然観察の森周辺は半径に海岸を含むため、ウミネコ・イソヒヨドリなど海辺の鳥が上位に入る(区域の限界)。
4. **穴2: 休園日の照合**(新規 `ikimonobiyori/closures.py`。通信しない)
   - 読める書き方: 毎月第N X曜(「第1・3月曜」)・毎週 X曜・「(祝日の場合は翌日/翌平日)」・「(祝日の場合は開園)」・「M月D日～M月D日」「M/D〜M/D」(年をまたいでよい)。祝日は内閣府の規則(固定日・ハッピーマンデー・春分/秋分の近似式・振替休日・国民の休日)で計算する。
   - 読めない規則(「年末年始」「臨時休園」など)は照らさず、原文を添える。
   - `facts` の各候補に `closed_on[]`(`closed`・`facility`・`line`)。舞岡公園: 「11/2(月)は小谷戸の里が休みです(公園には入れます)。」/ 11/3(文化の日)・11/4 は休みでない。
5. **出所の区分**: 境川遊水地のブログは、ページに「このアカウントは、神奈川県立境川遊水地公園の指定管理者である(公財)神奈川県公園協会が運用しています。」とあることを確かめ、`operator_evidence` として名所の一覧に残した(公式の扱いのまま)。座間谷戸山公園の鳥ごよみの URL を、証明書が切れた旧ホストから `www.kanagawa-park.or.jp/zamayatoyama/...` に直した。
6. **記録の結果をページごとに**: `record` の出力に `by_url`(ページごとの新しい記録・重複の数)を足した。ハブの窓口は「読み直しました」をこの数だけから作る。
7. CLAUDE.md・AGENTS.md(同じ内容)の「観察の記録と答えの材料」に段階35の規則を足した。
