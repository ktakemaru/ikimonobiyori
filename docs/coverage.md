# 探索範囲のデータの棚卸し(段階72 第4部 1)

`python -X utf8 -m ikimonobiyori.ask coverage` の結果(2026-11-10。通信なし)。段階73 の収集の計画に使う。

- 範囲の都県: 既定の出発地(横浜)から、地域の辞書(`data/regions.yaml`)の代表点が範囲の端(240km)より近い都県と、代表点のない「範囲の中」の地域の都県(コードで決める。`coverage.range_prefectures`)。愛知県(名古屋市の代表点 約249km)は範囲の端なので入れない。新潟県・福島県・岐阜県は一部だけが範囲(範囲の外の代表点もある)。
- 数え方: 名所の数(同じ都県・同じテーマで同じ名前は 1 回)。名所カタログ・ガイドの名所・観察の名所(リポジトリ)と、データ置き場の読んだ記録・知識カード(答えに出せるもの)。花は例年の時期の始まりの月で季節に分ける(時期の分からない記録は「時期不明」)。山のカードは山の座標から代表点のいちばん近い都県(目安)。承認済みの情報源は、その情報源が対象にする名所の都県。
- 「(都県不明)」は、読んだ記録・カタログに都県が書かれていないもの(段階73 で都県を補う)。
