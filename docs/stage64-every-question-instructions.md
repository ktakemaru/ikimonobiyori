## 4. 第3部: 種の名前で引く、季節を問わない「いつ・どこ」の答え

1. **意図の分類を足す**: 「<種や花の名前>の場所と時期」「いつどこへ行けばいい」「有名なスポット」「群生地」など、**日付を聞いていない「いつ・どこ」の質問**を、新しい型「時期と場所」とする（`intent.py`）。「今の時期」「今週末」など日付があるときは、これまでの計画の型。
2. **種の名前の解決**: 質問の語（ひらがな・カタカナ・漢字・別名。例: 紫陽花／あじさい／アジサイ、彼岸花／曼珠沙華／ヒガンバナ）を、次のどこかの**種・見どころの語**に結びつける。
   - 名所カタログ（`data/catalog/*.yaml` の `flower_kinds`・`kind` など）
   - ガイドのカタログ（`data/guide/catalog.yaml` の `kinds`）
   - 種ごとの花期（`wildflower_species.py` のデータ）
   - 野鳥のカタログ・知識カード
   別名辞書は設定ファイルに置く。ニッコウキスゲで、霧降高原と霧ヶ峰がカタログから出ることを受け入れ条件にする。
3. **答えの形（コードが作る）**: 「時期の早い順」に、名所ごとに「名所名（都県・市町村）、例年の時期、見どころ（種・本数など記録のある事実）、出発地からの距離」。先頭に1文で「例年○月〜○月が目安です」。今が時期外なら「今は時期の外で、次は○月ごろです」と1文。**今の日付で候補を絞らない。**種が複数（藤の白藤・大藤など）のときは、記録があれば並べる。表の形（場所×例年の時期）も出せるようにする（本人の会話で読みやすかった形）。
4. **1か所に複数の花**: 名所の `flower_kinds` に複数の種を持てることを確かめ、西平畑公園（河津桜・菜の花）のように、公式ページで確かめられた種を足す（第6部で）。
5. **地域の絞り込み**: 「神奈川県内」「東京の」など都県の指定は、すべての型で、都県の外を出さない（段階62で計画の型だけ直した部分を、全部の型に広げる）。
6. **記録がない種**: 「この種の名所は、確かめられた記録がまだありません」と1文で書き、第5部の手順で取得して記録してから、`ask answer` を呼び直す。
7. テストを足す（合成データ）: 時期外でも候補が出る／種の別名の解決／ニッコウキスゲでカタログの2か所が出る／都県の外が出ない／範囲外が出ない。

## 5. 第4部: 知識の質問、写真つきページ、場所の質問を `ask answer` につなぐ

1. **知識の型**（「〜について教えて」「〜とは」「〜の違い」「〜というのもあるんだ」）は、`ask answer` が知識カードの答え（段階59の型: どんなもの → 違い → 見分け方・出会い方 → いつ・どこ（最後に短く）→ ガイドの目）を作る。「冬から春にかけて見られる桜について教えて」は、**冬桜・寒桜・河津桜などの違いが先**、名所は最後に短く。
2. **知識と場所の混ざった質問**: 知識の段落のあとに、第3部の「時期と場所」の短い一覧（最大5件）を付ける。
3. **写真つきページ**: `ask answer` の答えの型（計画・時期と場所・知識）ごとに、同じ内容のページを作れるようにする（段階63の積み残し）。知識の型のページには、知識カードの事実（「ガイドの目」）を入れる。季節で絞った質問（「冬から春の桜」）は、その季節の種だけのページにする。手書きの HTML で代用しない決まりは維持。
4. **場所の質問**（`ask place`。段階63の積み残し）を `ask answer` から呼ぶ。「神奈川県の松田で有名なところ」は、松田町内の名所をカタログから出し、足りなければ第5部の手順で取得する。
5. テストを足す（合成データ）。

## 6. 第5部: カタログにないものを、取得して記録する手順（エージェント）

1. **検索の要約を事実にしない。** 検索で見つけたページは、**本文を取得して読み**（キャッシュの決まりは63bのとおり）、そこに書かれた事実だけを記録する。本文を読めなかったものは記録しない。
2. 1つの事実に1つの出典。出典は、公式（自治体・観光協会・施設・公園の管理者）を先に探す。紹介サイトだけの事実は「公式ではありません」の区分で記録する。
3. **強い事実**（災害・閉鎖・規制・休園・火事・通行止め・料金）は、**公式ページで確かめたものだけ**記録する。紹介サイトだけのときは記録しない。
4. 範囲（出発地から 250km 前後）の外は記録しない。年の分からない日付は、行事の期間として記録しない（曜日チェック）。
5. 1回の質問で取得するのは最大3ページ（63b）。足りなければ、記録できた分で `ask answer` を呼び直して答える（「ご希望なら調べます」と書かない）。
6. スキルの手順に、上の1〜5と、「**答えの本文は `ask answer` の出力だけ。自由な文章で答えない**」を明記する。スキルの大きさは15KB以下を保つ（63b）。
7. テストを足す（検索の要約だけの事実が記録で拒否される／範囲外が拒否される／強い事実が紹介サイトだけでは拒否される）。
