## 3. tenki.jp を外す
1. tenki.jp を、読む対象（summary_pages・名所の pages・取得コマンドの対象）から**外す**。台帳には「人が開くリンク（取得しない）」として残す。
2. 段階34〜45 で tenki.jp から読んで記録した値（status_log の tenki.jp 由来の記録、神奈川18件、奥多摩・高尾山5件など）を、**答えの材料から外す**。
   - 手元の runtime の記録は、削除せず、答えの材料にならない場所（例：runtime の archive フォルダ）に移す。移したファイルと件数を報告書に書く。
   - リポジトリにコミットされた tenki.jp 由来のデータ（名所カタログの出どころ、例年の時期、テストの入力・ゴールデン）がないか調べる。ikimonobiyori は公開リポジトリ（public）なので、あれば一覧にして報告書に書き、除去する。除去してテストの期待値が変わる場合は、期待値を変えずに済む方法を優先し、変える場合はその理由を報告書に書く。
   - 外した後、答えの材料に tenki.jp 由来の記録が1件も残っていないことを、確認用のコマンドで確かめ、報告書に書く。
3. 外すことを防ぐテストを書く（tenki.jp が読む対象に入っていないこと、答えの材料に出てこないこと）。
