# ガイドの書き方(段階75・78)

材料は `ask brief` の資料だけ。手順は docs/guide-mode.md。**送るのは `ask verify` の出した文だけ(前にも後ろにも何も足さない)。**

## 1. 組み立て(この順番で書く)

1. **質問への答えを1〜2文で**。知識の質問(「〜とは」「違い」「なんというの」)は知識を先に。名前を聞かれたら、聞かれた現象の名前をまず答える。
2. **なぜ今か**: 資料の「語りの材料」の「なぜ今」から1〜2点を、文にして印を付ける。
3. **場所ごとに**(2〜4か所): 確かめた事実(今年の現況は日付つき、または例年の目安)と、「どこをどう見る」の材料。場所の名前は太字にしてよい。
4. **注意**: 冬季閉鎖・通行止め・作法(資料にあるものだけ)。
5. 出典は書かない(合格すると自動で付く)。

- 箇条書きの一覧だけで終わらせない。語りは文で書く。箇条書きは場所の並びにだけ使う。
- **材料があるときは、まず材料を使う**(「語りの材料」から少なくとも1点。使ったら [K…] を付ける)。「材料なし」の種類は書かない。
- 自分の知識で足してよいのは、季節や環境の一般的な説明だけ(「冬鳥は秋に北から渡ってくる」「標高が高いほど時期が遅い」など。場所・日付・行事は足さない)。
- **種の見分け方・特徴**(散り方、花や葉の形、色、大きさ、くちばし・羽・尾の特徴、鳴き声、毒、似た種との違い)は、**カードにあることだけ**を書き、そのカードの印 [K…] を付ける。カードがなければ書かない(資料に「○○の見分け方・特徴は、資料にありません」とあるときも書かない)。段階82(本人の判断 2026-11-12。段階79 の判断4 を改めた)。
- 目安は400〜900字。見出しは2〜4個まで。

## 2. してはいけないこと

- 前置き・作業の説明(「資料から書きました」「検査に合格しました」「そのまま送ります」)
- 英語の文・メモ
- 最後の質問(「〜しますか」「いかがでしょう」「?」)
- 資料にない日付・時刻・行事・料金・電話・通行止め
- 内部の言葉(資料・カード・記録・検査・id・印)
- 手本の例文をそのまま写すこと

## 3. 確かさの3段

| 段 | 書き方 | 材料 |
|---|---|---|
| 公式で確認(日付つき) | 「11月9日時点、長瀞町観光協会の発表では見頃を迎え始めています」 | 今年の現況の事実 |
| 例年の目安 | 「例年は11月中旬から下旬が見頃です」 | 例年の目安の事実・カード |
| 一般的な知識 | 「カエデは寒暖差が大きいほど赤が濃くなります」 | 自分の知識(季節・環境の説明だけ。種の見分け方・特徴はカードの印つきで) |

公式でない出どころは文中で「紹介サイトによると」と短く書く(長い断りは書かない)。

## 4. 印を付ける文(資料にあるときだけ書く)

今年の現況・具体的な日付と時刻・行事の名前と期間・開園時間・料金・電話・通行止めや閉鎖・**特定の名所の例年の時期**。文の終わりに資料の id(`[F012]`・`[K034]`)。値(日付・状態の語)は事実とそろえる。

- 今の状態の文は「今年の現況」の事実が根拠(例年・行事の印では通らない)。
- 数日前の現況を、対象の日の状態として言い切らない。だめ:「今週末、足尾は真っ盛りです」。よい:「11月7日時点では真っ盛りでした。今週末は盛りを過ぎているかもしれません」。
- 行事の期間を見頃として書かない。来週末など先のことは「見込み」で書く。
- 印なしで書ける日付は、今日・今週末・来週末・対象の日だけ。
- 距離は「直線で約○km」。資料に「東京湾の向こう側」とある場所は数字を書かない。

## 5. 資料の使い方

- 候補: 「今年の現況あり」は日付つきで、「例年の目安」「種の名所」は「例年は○月ごろ」で。「例年の時期の記載があいまい」「古い年の記載」とある名所は、そのことを一言添える。
- カードの「一般の話」は一般の説明としてだけ使い、特定の場所・行事に結びつけない。
- 足りないもの: 隠さず利用者の語で一言(「霞ヶ浦の今年の観察の記録は多くありません」)。
- 資料にない場所を自分の知識で添えるのは3か所まで。範囲(横浜から片道250km前後)の都県で、「今年の状況は確かめていません」と同じ文に書く。
- 野鳥は正確な場所を書かず、近づきすぎない・餌をやらないを一言。
- 使わない: ウェザーニュース(転載を含む)・tenki.jp・日本気象協会の予想、SNS。

## 6. 悪い例とよい例(同じ材料から。例をそのまま写さない)

材料: [F001] 試験の渓谷: 見頃(11/9時点、試験町観光協会)/[K001] なぜ今: 紅葉は冷え込みの早い谷の上から下りてくる/[K002] どこをどう見る: 吊り橋から谷を見下ろすと色の重なりが分かる

悪い例(一覧だけ):
> - 試験の渓谷: 見頃(11/9時点)
> - 例年11月中旬

よい例(ガイドの答え):
> 試験の渓谷が、ちょうど見頃に入ったところです。11月9日時点で、試験町観光協会は見頃と伝えています。[F001] 紅葉は冷え込みの早い谷の上の方から始まり、少しずつ下りてきます。[K001] 吊り橋の上から谷を見下ろすと、上と下で色づきの違う重なりがよく分かります。[K002]

### 種の特徴の悪い例(段階82。実際にあった誤り)

質問「さざんかの見頃と見どころを教えて」で、カードを使わずに自分の知識で書いて、逆のことを書いた:
> サザンカは、花びらが一枚ずつ散らず、花ごと落ちることが多い花です。

実際は逆(花ごと落ちるのはツバキ。サザンカは花びらが1枚ずつ散る)。カードにある文だけを、印つきで書く:
> 花の似ているツバキは花ごと落ちますが、サザンカは花びらが1枚ずつ散ります。[K004]

## 7. 下書きの形

```
(本文。印は文の終わりに [F012] や [K034])

[場所]
記録: 高尾山、長瀞
知識: 御岳山(東京都)
```

`[場所]` の「記録」は資料・名所の辞書にある場所、「知識」は自分の知識で添えた場所(都県つき)。なければ「なし」。
