# 生き物の答えの評価表(受け入れテストの採点に使う本文)

段階37 で、biyori-hub の `docs/concierge-rubric.md`(段階H10。指示書 `docs/ikimonobiyori-rebirth-instructions.md` 1章の R1〜R11 と、
段階H9・H10 の追加の合格基準)の生き物の部分を、イキモノビヨリに移した。R4 の本文は、利用者の決定(2026-11-01。H10 の決定1。前回の確認事項1の (b))のとおり。
R10 には、段階37(指示書 `docs/stage37-H11-instructions.md` 2-3)で、開発・作業の言葉と作業の経過の文を足した。
**採点者に渡すのはこの文書の「評価表」と「追加の合格基準」と答えだけ。** ここに書いていない読み方を、採点者に添えない。

## 評価表

| # | 条件 |
|---|---|
| R1 | 冒頭の1〜2文で、全体の結論(今が見頃か、まだ早いか、どこが近いか)を言う |
| R2 | 指定の地域(例: 神奈川)の候補を**3件以上**出す。地域に合わない候補は、県外と明示して分ける |
| R3 | 各候補に、**今の状態**(青葉・色づき始め・見頃・見頃過ぎ、花なら見頃前・見頃 など)と**その日付**と**出所**を書く。分からなければ「今の状態は分からない」と書いたうえで、例年の時期で出す |
| R4 | 各候補(番号つきのおすすめ・「ほかの候補」など、答えに名前を挙げて勧める名所のすべて)に、**例年の見頃**を書く。野鳥は「例年の見頃」の代わりに「**この時期に見られる鳥**」(出典つき)を書く。**例年の見頃(野鳥はこの時期に見られる鳥)が分からない候補は、「例年の時期は分かりません」と明言し、代わりに今年の行事の期間か、昨年(前の年)の記録を書けば、R4 を満たす。** 分からないことを理由に、候補を答えから外さない。(今年の行事も昨年の記録も、答えの材料にない候補は、「例年の時期は分かりません」の明言だけで R4 を満たす。) |
| R5 | 各候補に、**なぜそこか**(近い・今いちばん進んでいる・これから進む・行事がある など)を一言 |
| R6 | 該当があれば「避けたほうがよい場所(まだ早い・終わった)」と、別の目的での代わり(例: 菊花展)を出す |
| R7 | 確かさの補足(いつ時点か、公式か紹介サイトか、去年の情報か)を短く出す。**止める理由にはしない** |
| R8 | 最後に、好みを1つ聞く(どちらを重視しますか? など)。答えの本体は先に出す |
| R9 | 出典の URL を最後に並べる |
| R10 | 次の言い方が**1つも出ない**: 「材料がない」「情報がない」「おすすめを出せません」「使える期限を過ぎている(ので使わない)」「更新は私からは始めません」「! を付けて」「実行してください」「承認してください」「集めた事実だけを並べます」、内部用語(snapshot、status_log、proposal、band、max_age_h、pending、台帳 など)、作業の経過(「検査が通ったので」「答えを出します」「あとは答えを書くだけです」「今回は取りに行っていません」など)、開発・作業の言葉(「テスト」「コード」「作業メモ」「記録済み」「スキル」「コマンド」など) |
| R11 | スマホで読める長さ(目安 1,500字以内。字数で測る) |

## 追加の合格基準(段階H9・H10・段階37)

| # | 条件 |
|---|---|
| A1 | 答えの末尾の「○/○ に ○○ を読み直し、新しい記録が N件増えました」(または「読みに行きましたが、新しい情報は取れませんでした」)は、この回の記録の結果(ページごとの、本当に増えた新しい記録の数)と一致する。新しい記録が 0 件のページを「読み直しました」と書かない |
| A2 | 野鳥: 神奈川の探鳥地を3件以上。各候補に「この時期に見られる鳥」(出典つき)。「例年の見頃」の語がない。対象の日に休みの名所は、休みを言い切る |
| A3 | 状態の日付が古い名所は読み直している(読めなければ「読みに行きましたが、新しい情報は取れませんでした」と書いている)。例年の時期と今年の行事が区別されている(今年の行事の期間を「例年の見頃」と書かない) |
| A4 | 野鳥で、iNaturalist の集計が新しければ取り直していない(呼び出しの記録 `calls.json` の `inat_refresh` が `skipped: fresh`)。古い・対象の日が期間外なら、計測フックの下で取り直している(1 回の質問につき 10 リクエストまで)。計測フックがない単体の実行では取り直さず(`skipped: no_measure_hook`)、古い集計を日付つきで使う |
