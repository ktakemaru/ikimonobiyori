| 目安 | 結果 |
|---|---|
| 「お答えできません」は出どころが 1 件もないときだけ | 使わなかった(ヒメボタルの名所・東京港野鳥公園のカワセミは「確認できなかった」と探した言葉を書いた) |
| 聞き返さない | 聞き返していない |

| 内部の言葉・作業メモが本文にない | 本文に出していない(表は作業メモ) |
| 記録の読んだ時刻がパソコンの時計 | 試験で書いた記録はすべてコードの時計。未来の時刻 0 件 |
