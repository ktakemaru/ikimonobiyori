# ガイド型の質問の試験(段階23)

段階23 の指示書の付録B(ユーザーが 2026-10-25 に実際にした質問)と、合格の目安。試験の結果は `docs/stage23-trial.md`。
答え方の手順は `.claude/skills/ikimono-weekend/SKILL.md` の「現況型とガイド型」「ガイド型の答え方」。

**ユーザーが、2026-10-25 に実際にした質問**です。それぞれ、スキルの手順で答え、合格の目安を満たすか、自己判定する。

| # | 質問 | 合格の目安 |
|---|---|---|
| Q1 | 都内の野鳥の名所をリストアップして、冬の渡り鳥を教えて | 名所6件以上(段階つき)、冬の渡り鳥の種類8種以上と時期、出どころの区分 |
| Q2 | 今の時期(10月下旬)見られる渡り鳥を教えて | 「今」の記録(日付つき)と、「これから増える鳥」を分けて書く。範囲外の名所(瓢湖など)を、おすすめに混ぜない |
| Q3 | 関東地方で一番早い桜はどこでいつ頃見られますか? 何箇所か教えて | 咲き始めの早い順に、5か所以上。冬桜(今から)と、来春の早咲き(1月下旬〜)を分ける。年による前後を書く |
| Q4 | 冬桜とは何? 寒桜との違いは? | 2つが別の種であること、時期、名所(城峯公園・桜山公園)。出典の区分つき |
| Q5 | 紅葉と桜が同時に楽しめるところは? | 桜山公園、城峯公園。時期が重なる月 |
| Q6 | 関東の蛍の名所、場所と時期とホタルの種類を教えて | 8か所以上、種類(ゲンジ・ヘイケ)、時期の早い順。**ヒメボタルは、名所が見つかれば書き、見つからなければ、「確認できなかった」と書く** |
| Q7 | カワセミが見られる場所を教えて | 「聞き返さない」。石神井公園・光が丘公園・東京港野鳥公園(今季の記録)など、**出どころつき**で。見つからなければ、探した言葉を書く |
| Q8 | さざんかが見られるところを教えて | 名所と時期(例年10月下旬〜2月)。「お答えできません」にしない(検索して、独立した出どころが見つかった場合) |
| Q9 | ロウバイやツバキの名所と季節を教えて | 名所と時期。見つからなければ、理由と探した言葉。一般知識は「補足」2行まで |
| Q10 | 梅の名所を教えて | 都内3か所以上と時期 |
| Q11 | 富士山周辺で花の見られるスポットは? その花の種類と季節も | 山梨側・静岡側の名所と、花の種類、季節。範囲(250 km)の判定つき |
| Q12 | 一番早く咲く桜の名所を教えて | Q3 と同じ内容を、1つに絞って答える |
| Q13 | バラはどこで見られますか? | 登録済みの名所(旧古河庭園・神代植物公園・京成バラ園・ひたち海浜公園)。**同じ日に読んだ記録があれば、聞き返さず使う** |
| Q14 | 都内で紅葉が楽しめるところは? | 庭園(六義園・小石川後楽園・新宿御苑・昭和記念公園)の、例年の時期。「今の状態」は、日付つきの公式の現況があるときだけ |
| Q15 | 渡り鳥を見たい | 「渡り鳥」が決まった対象に結びつく(言い換えの対応表)。Q1・Q2 に準じて答える |
| Q16 | 今楽しめる花は? | 現況型。同じ日の記録を、聞き返さずに使う。日付つき |
| Q17 | ホタルが見たい。電車で行けるところは? | Q6 の名所から、電車で行けるものを選ぶ(交通の記載がない名所は、「要確認」) |

**共通の合格の目安**:
- 「お答えできません」を、**独立した出どころが1件も見つからなかったときだけ**使う。
- **聞き返さない**(承認の範囲で、読む)。
- 数字は大まかでよい。**確かめていない種名・数字は、「要約で読んだ」ものとして、独立した出どころ2件以上があるときだけ本文に出す。**
- 内部の言葉・作業メモが、答えの本文に出ていない。
- 記録の読んだ時刻が、**パソコンの時計**から入っている(未来の時刻がない)。
