### 第3部: 仕組み
- カードに地点 id(`sites`: mNNN)を持たせ、「見どころ」の型で地点 id でも引く。
- 季節の花など月のあるカードは、今の月に近いものを先に。
- 山の名前で聞かれたときの名所の半径を 10km → 5km(隣の町の名所が混ざったため。`data/ask/highlights.yaml`)。
- 冒頭の「自然の特徴」に、行き方・歩き方のカードを使わない。
- 名所の名前でカードを引くときはカードの主な場所だけで当てる(大山の答えに、別名「丹沢」を持つ外来種のカードが出たため)。種の解説は名所の名前では引かない。
- 答えの見出しは質問に書かれた語(「高尾山」を辞書の「高尾」にしない)。
