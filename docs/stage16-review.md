# 段階16 見直し用の一覧: 足した情報源と名所(紅葉・冬鳥)

ユーザーが見直して、仮承認を取り消せるようにするための一覧。台帳は `ikimonobiyori/data/sources/<対象>.yaml`、名所カタログは `ikimonobiyori/data/catalog/<対象>.yaml`。

- 読んだ日: 2026-10-23(JST)。各ページを 1 回(robots.txt・利用条件のページも 1 回ずつ)読んだ。
- 読み方: WebFetch(要約の道具)。記号・日付・規約の文は道具が示したもので、**原文との照合は人の目でしていない(要目視)**。館林市・三条市の利用条件は検索の要約で確かめた(D-52)。
- 仮承認の条件(段階15 と同じ): ① 発信者が公式、② ページを実際に読めた(拒否されていない)、③ 利用条件が要約や出典つきの事実の利用を禁じていない。**すべて**満たすものを `approved_by: claude_code_provisional`(`approved_on`/`approved_at: 2026-10-23`)にした。
- 「著作権法上認められた引用などを除き無断で複製・転載できない」は、状態と更新日の短い事実を出典つきで示すだけなら当たらない、という段階15 のユーザーの判断(2026-10-23)に合わせた。
- **取り消し方**: 台帳の `approval` を `{status: revoked, reason: "..."}`(または `pending`)に、カタログの件を `status: candidate` か `retired` にして、`python -X utf8 -m ikimonobiyori.sources check` と `python -X utf8 -m ikimonobiyori.catalog check` を通す。カタログの件を外すときは、台帳の covers の `site` を `name` に直す(検査が一致を見る)。
