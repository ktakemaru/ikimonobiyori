# 組み合わせの例: ヤマビヨリの山 + イキモノビヨリの花（段階40）

コンシェルジュ（ハブ側。将来）が、ヤマビヨリの山の候補に、イキモノビヨリの `guide wildflower` を添える出力のイメージ。ヤマビヨリの出力は例として手で書いた（実通信なし）。

## 入口（通信しない）

```
python -X utf8 -m ikimonobiyori.guide wildflower --site m022 --month 5 --json
python -X utf8 -m ikimonobiyori.guide wildflower --site m022 --month 5          # そのまま添えられる短い文
```

`--site` はヤマビヨリと同じ識別子（m022 = 塔ノ岳）。`--json` は `ikimonobiyori/schemas/wildflower.schema.json` に従う。

## ヤマビヨリの候補（手書きの例）

> 塔ノ岳（神奈川・標高 1491 m）: 5月第3土曜は午前中が晴れの見込み。登山口 8 時発なら 14 時までに下山できる見込み。（山の天気・コースはヤマビヨリの判断）

## イキモノビヨリが添える文（`guide wildflower` の出力そのまま）

> 5月の塔ノ岳（丹沢）では、シロヤシオ(標高約1350〜1500m)・トウゴクミツバツツジ(標高約600〜1500m)・サンショウバラ・ツルシロカネソウ・ヤマツツジ(標高約1100〜1200m)が例年見られます。来月（6月）は、ギンリョウソウ・ケイワタバコ・シモツケ・ワチガイソウが例年の見ごろに入ります。例年の時期の目安です。今年の開花は読めていません。花は採らず、登山道から出ずに、踏まないようにしてください。山の天気はヤマビヨリで確かめてください。

## 合わせた提案文のイメージ（コンシェルジュが書く）

> 今度の土曜は塔ノ岳がおすすめです。天気は午前が安定していて、（ヤマビヨリの判断）。花も楽しめます。5月は標高1350〜1500m付近でシロヤシオ、標高約600〜1500mでトウゴクミツバツツジが例年見られます（例年の時期の目安で、今年の開花は読めていません）。花は採らず、登山道から出ないでください。

## 注意

- 保護が必要な種（ラン科・希少種）は `--site` の出力に出ない（山域の出力 `--area` にだけ出る）。
- 地点がまだ山域に結ばれていない山、または山域が準備中のときは、`status: preparing`（「データ準備中」）を返す。
