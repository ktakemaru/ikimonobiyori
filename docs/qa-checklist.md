# 試験問題: 質問と期待する振る舞い(段階16 D、段階17 で 11〜16 を追加)

イキモノビヨリに手を入れたときの物差し。スキル `.claude/skills/ikimono-weekend/SKILL.md`(`AGENTS.md`・`CLAUDE.md` の「生き物の見頃・おすすめ」と同じ手順)で答え、下の期待を満たすかを確かめる。
答えの記録は段階ごとに `docs/stageNN-trial.md` に残す(公式ページの文章は写さない)。

共通の期待(すべての質問。段階17 で答えの形を足した):
- 結論(今回のおすすめ)を先に。内部用語(方針 `answer.forbidden_terms`)を出さない。同じ名所を 2 か所に出さない。地点ごとの日付は「○/○時点」の 1 つ。
- 公式の状態は原文の表記のまま(共通の段階は括弧)、公式の更新日と新しさ、出典 URL を名所ごとに付ける。
- 承認済みの情報源だけを読む。読めなかった名所(人が開く URL)と、推定だけの名所(例年の時期・公式の見頃予測・v0)を、おすすめと分けて示す。
- 食い違い(`conflicts`)・表示が古い可能性(`stale_display_suspect`)は、おすすめに使わず別に示す。
- 日付・時刻は年月日とオフセットを省かない。
