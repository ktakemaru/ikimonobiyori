# 段階23 見直しの一覧(ガイド型の名所)

**朝の見直し(5 分)のしかた**
1. 下の各テーマの「仮承認」の表だけを見てください(候補のままのものは、答えのおすすめに出ません。折りたたんであります)。
2. おかしいもの(閉園した・名前が違う・場所が違う・その花や鳥の名所ではない)があれば、id を控えて、次のように外してください。外したものは、同じ候補が再び仮承認されません。
   ```
   python -X utf8 -m ikimonobiyori.guide reject <id> --reason "<理由>"
   ```
   (手元の記録に残ります。リポジトリに残す場合は、Claude Code に「外した名所を reviews.yaml に写して」と頼んでください。)
3. 「行って確認した」名所は `python -X utf8 -m ikimonobiyori.guide visited <id>` で「確認済み」になります。

**読み方**
- 段階: 定評 = 独立した出どころ 3 件以上(個人の発信だけではない)/ 確認済み = 運営者の日付つきの状態を読んだ、または行って確認した / 参考 = それ以外。
- 独立した出どころ: 同じ発行元(るるぶ と るるぶKids など)・書き写しは 1 件と数えた数(コードが数える)。
- 区分: A 運営者の発信 / B 公的機関の資料 / C 報道・観光メディア / D 個人の発信。
- 種類・時期は、独立した出どころ 2 件以上が言うものだけを表に出し、1 件だけの時期には「(1件のみ)」と付けました。
- 所在の距離は、市区町村の代表点(Wikidata)から横浜・東京それぞれまでの直線距離。答えでは出発地(既定は横浜)から測り、240〜250 km は「範囲の端」、250 km より先は「範囲の外」(おすすめに出さない)。仮承認は、横浜・東京のどちらかから 250 km 以内のもの。
- 出典の URL・読んだ時刻は `ikimonobiyori/data/guide/catalog.yaml`(仮承認)と `candidates.yaml`(候補)にあります。
